\section{結論と今後の課題}\label{sec:conclusion}

本稿では、確率的ボラティリティ（SV）モデルのベイズ推定を変分推論（VI）で行うことが、金融機関向けシステムの実務に使えるかを、
精度・計算時間・運用性の三つの観点から評価し、使えるとすればどのように使うべきかを検討した。
\cref{sec:conc-summary}で本稿の結果をまとめ、\cref{sec:conc-implications}で実務への示唆を、\cref{sec:conc-limitations}で本稿の限界を、
\cref{sec:conc-future}で今後の課題を述べ、\cref{sec:conc-closing}で本稿を締めくくる。

\subsection{本稿のまとめ}\label{sec:conc-summary}

\subsubsection{問い}

SV モデルは、ボラティリティそのものを確率的に変動する潜在変数として扱うモデルであり、ボラティリティの集中や裾の厚さをよく説明する（\cref{sec:model}）。
しかし、潜在変数がデータの日数 $T$ と同じだけあるため、尤度を閉じた形で計算できず、ベイズ推定には MCMC が使われてきた。
MCMC は正確であるが、系列が長くなるほど、また銘柄が多くなるほど計算が重くなり、日次でリスクを計算するシステムに組み込むには負担が大きい（\cref{sec:intro}）。
VI は、事後分布を最適化によって近似することでこれを速くする手法であるが、近似の仕方（変分族）を誤ると結果が大きく偏る（\cref{sec:inference}）。
本稿の問いは、「SV モデルに対して、実務で信頼して使える精度の VI を、実務で使える速さで実現できるか。できるなら、システムとしてどう運用すべきか」であった。

\subsubsection{精度：変分族の設計が結果を決める}

\paragraph{汎用的な族は使えない}
もっとも単純な平均場近似（各変数を独立とする族）は、持続性 $\phi$ の推定に失敗した。
真値 0.80〜0.99 のすべてのシナリオで、$\phi$ の推定値は 0.03〜0.09 程度（複製の平均）に崩れ、データを増やしても、パラメータ化を変えても改善しなかった（\cref{sec:syn-recovery,sec:syn-sensitivity}）。
\cref{sec:inf-vi}で示したとおり、これは最適化の失敗ではなく、平均場の族の中での最適解である。
$\phi$ が大きいほど $h_t$ の時間方向の相関が強く、平均場近似の誤差（KL の最小値）が大きくなるので、ELBO は小さい $\phi$ を好む。
パラメータを増やした低ランク・フルランクの族も同様に崩れ、約 50 万個のパラメータを持つフルランクの族は 230 秒かけても $\phi = 0.24$ にとどまった（\cref{sec:syn-agreement}）。
「パラメータを増やせば近似が良くなる」わけではなく、事後分布の構造に合った族を選ぶことが本質である（\cref{sec:fam-dense}）。

\paragraph{構造を入れても、依存を落とすと失敗する}
$h$ の事後分布の三重対角の精度行列を取り入れた構造化の族は、$h_t$ の推定は良好であったが、パラメータ $\theta$ と $h$ を独立としたために、
$\sigma$ の不確実性を 1/5〜1/10 以下に過小評価し、$\sigma$ の 95\% 区間はほとんど真値を含まなかった（\cref{sec:syn-recovery}）。
$\sigma$ の事後標準偏差は $\sigma/\sqrt{2(T-1)}$ という「$h$ が観測されているとした場合」の値まで縮み（\cref{sec:fam-structured}）、
$\sigma$ の点推定も、シナリオによって過大にも過小にも偏った。

\paragraph{条件付き構造化の族は NUTS とほぼ一致する}
$\theta$ を条件にした $h$ の分布を、$\theta$ ごとのラプラス近似と同じ形 $q(h \mid \theta) \propto p(h \mid \theta) \prod_t \Normal(\tilde y_t \mid h_t, \lambda_t^{-1})$ で表す条件付き構造化の族（\cref{sec:fam-conditional}）は、
時間方向の相関と $\theta$–$h$ の依存の両方を $O(T)$ の計算量で表せる。
合成データでは、$\phi$・$\sigma$・$h_t$ の推定誤差は NUTS と同程度で、$\sigma$ と $h_t$ の区間は名目どおりの被覆率を持った（\cref{sec:syn-recovery}）。
十分に長い NUTS との比較では、高持続シナリオで $\phi$ の事後平均が 0.983（NUTS 0.983）、$\sigma$ が 0.123（同 0.126）、$h_t$ の事後標準偏差は NUTS の 0.98 倍であった（\cref{sec:syn-agreement}）。
実データ（ETF 2 銘柄）でも、$h_t$ の事後標準偏差は長い NUTS の 0.93〜0.95 倍、事後平均の差は NUTS の事後標準偏差の 0.04 倍で、潜在ボラティリティの推定は NUTS とほぼ見分けがつかなかった（\cref{sec:emp-full}）。
この族は、中心化・非中心化のどちらのパラメータ化を使っても同じ分布の集合になり（\cref{sec:fam-conditional}）、実験でも同じ結果を与えた（\cref{sec:syn-sensitivity}）。

\paragraph{ただし、系統的な差は残る}
提案手法にも、NUTS との系統的な差がある。
\begin{itemize}
  \item パラメータの不確実性をやや狭く見積もる。合成データで $\phi$・$\sigma$ の事後標準偏差が NUTS の 0.84〜0.93 倍、実データでは 0.73〜0.86 倍であった（\cref{sec:syn-recovery,sec:emp-full}）。
  \item 実データの 32 銘柄すべてで、$\sigma$ を NUTS より小さく（中央値で約 $-8.5\%$）、$\phi$ をわずかに大きく推定した。差は NUTS の事後標準偏差の 0.62 倍以内である（\cref{sec:emp-multi}）。
  \item レバレッジ SV の相関 $\rho$ を、0 の側に約 25\% 縮めて推定した（合成データ、$T = 2{,}000$。\cref{sec:syn-recovery}）。
    真の事後分布で $h_{t+1}$ が $h_t$ に非線形に依存する部分を、正規分布の族では表せないためである（\cref{sec:fam-leverage}）。
  \item 持続性が高いとき、$\mu$ の不確実性を過小評価した（$\mu$–$\phi$ のバナナ型の依存。\cref{sec:syn-recovery}）。
\end{itemize}

\paragraph{誤った族はモデルの解釈まで変える}
実データの SV-$t$ モデルで、NUTS と提案手法は誤差の自由度 $\nu$ を 20〜25 と推定し、リターンの裾の厚さはほぼボラティリティの変動で説明できることを示した。
これに対して、平均場と構造化は $\nu$ を 5〜8 と推定し、ボラティリティの集中で説明すべき大きなリターンを、誤差の裾の厚さとして説明した（\cref{sec:emp-full}）。
表現力の足りない変分族は、パラメータの値を偏らせるだけでなく、「リスクがどこから来るのか」というモデルの解釈そのものを変えてしまう。

\subsubsection{計算時間：日次の運用に十分な速さ}

提案手法の計算量は系列長 $T$ に比例し（\cref{sec:fam-conditional}）、$T = 10{,}000$ でも ELBO が収束するまで約 11 秒で、NUTS（548 秒、しかもパラメータの ESS は 14）の約 50 倍速かった（\cref{sec:syn-scaling}）。
NUTS の所要時間は $T$ に対して超線形に増え、同じ時間で得られる有効サンプル数は $T$ とともに激減した。
実データの長さ（$T \approx 500$）で 1 系列を推定するだけなら、速さの差は数倍にとどまるが、
多銘柄・日次の運用では差が積み重なる。
32 銘柄（各 485 日）の全期間の推定は、NUTS（1 銘柄ずつ）で 293 秒、提案手法（8 デバイスに振り分け）で 15 秒であった（\cref{sec:sys-multi}）。
前日の結果から始める warm start による日次の更新は、1 銘柄あたり 0.10 秒（1 デバイス）、8 デバイスに振り分けると約 0.036 秒で、銘柄数に比例して伸び、2,000 銘柄でも約 70 秒と見積もられた（\cref{sec:sys-multi}）。

\subsubsection{運用性：VI を主役に、NUTS を監査役に}

\paragraph{予測性能}
推定窓 250 日のローリング推定による VaR のバックテスト（検証 235 日）では、提案手法による SV モデルの 5\% VaR の超過率は 6.4〜6.8\% で、
Kupiec・Christoffersen のいずれの検定でも棄却されなかった（\cref{sec:emp-var}）。
対数予測スコアは、両銘柄で SV モデルが GARCH(1,1)（正規誤差・$t$ 誤差）を上回ったが、差は 1 日あたり 0.03 nats 以下と小さく、
Diebold–Mariano 検定で有意だったのは 1306（TOPIX 連動 ETF）だけであった。
提案手法の VaR は、同じ日の NUTS の VaR との差が 0.02\% ポイント程度で、手法間（SV と GARCH）の差より 1 桁小さかった。
一方、平均場近似の VaR は 1321（日経 225 連動 ETF）で超過率 8.1\% となり、検定で棄却された。

\paragraph{日次の運用}
日々の推定の状態は、1 銘柄あたり約 4 KB の変分パラメータだけであり、warm start による更新の結果は、毎回ゼロから推定した場合と VaR で 0.02〜0.03\% ポイント（中央値）しか違わなかった（\cref{sec:sys-warm}）。
同じ乱数のキーを使えば結果はビット単位で一致し、並列化の方式（デバイスへの振り分け）によっても変わらなかった（\cref{sec:sys-repro}）。

\paragraph{監視とハイブリッド運用}
VI は最適化が終われば必ず答えを返し、平均場の例のように ELBO が順調に収束していても近似が大きく外れることがある。
そこで本稿では、実行ごとの確認、推定値の日次の連続性、週次の NUTS との突き合わせ、VaR のバックテストの継続、という 4 層の監視と、
日次の推定は VI、パラメータの解釈と VI の監査は NUTS、というハイブリッド運用を提案した（\cref{sec:sys-monitor,sec:sys-roles}）。

\subsubsection{結論}

以上から、本稿の問いに対する答えは次のとおりである。
\begin{quote}
  SV モデルの VI は、\textbf{事後分布の構造（$h$ の時間方向の相関と、$\theta$ と $h$ の依存）を取り入れた変分族を使えば}、
  潜在ボラティリティと VaR の水準では NUTS とほぼ同じ結果を、日次の多銘柄の運用に十分な速さで出せる。
  ただし、パラメータそのもの（とくに $\sigma$ と $\rho$）の推定には系統的な差が残るので、
  \textbf{VI を日次の主役、NUTS を定期的な監査役とするハイブリッド運用}と、その監視の仕組みとをあわせて導入すべきである。
  汎用的な変分族（平均場など）を既定の設定のまま使うことは、SV モデルでは避けるべきである。
\end{quote}

\subsection{実務への示唆}\label{sec:conc-implications}

本稿の結果から、SV モデル（および類似の状態空間モデル）を VI で推定するシステムを開発する際の指針を、開発者の立場からまとめる。

\begin{enumerate}
  \item \textbf{確率的プログラミングのライブラリの既定の変分族をそのまま使わない}。
    NumPyro の \code{AutoNormal}（平均場）や \code{AutoMultivariateNormal}（フルランク）は、書くのは簡単であるが、SV モデルでは $\phi$ が崩れた（\cref{sec:syn-agreement}）。
    状態空間モデルでは、まず事後分布の構造を調べ、それに合わせた変分族を設計する必要がある。
  \item \textbf{パラメータと潜在変数の依存を落とさない}。
    $h$ の時間方向の相関を入れるだけでは不十分で、$\theta$ と $h$ の依存（$\sigma$ が $h$ の滑らかさを、$\mu$ が水準を決める）を表せないと、パラメータの不確実性が失われる（\cref{sec:fam-structured}）。
  \item \textbf{「ELBO が収束した」と「近似が正しい」を区別する}。
    ELBO は同じモデル・同じデータでの変分族の比較には使えるが（\cref{sec:syn-agreement}）、近似の絶対的な良さは分からない。
    新しいモデルや変分族を導入するときは、必ず NUTS で正解を作って比べる。
  \item \textbf{自動診断の指標に頼りすぎない}。
    PSIS の $\hat k$ は、本稿の問題では提案手法でも常に目安を超え、合否の基準として機能しなかった（\cref{sec:sys-monitor}）。
    ELBO の相対変化による収束の判定も、ELBO の推定値の雑音のために、平らになった後は偶然に成立する（\cref{sec:sys-warm}）。
    指標の意味と限界を理解したうえで使う。
  \item \textbf{NUTS も検証の対象にする}。
    NUTS を正解として使うには、$\hat R$ と ESS を確認し、必要なら連鎖を長くする。
    本稿でも、各連鎖 2,000 回では多くの推定で $\hat R$ が目安を超えた（\cref{sec:sys-roles}）。
  \item \textbf{用途に応じて推定方法を選ぶ}。
    ボラティリティと VaR の日次の計算には VI、パラメータの値そのもの（$\sigma$ のシナリオ生成、$\rho$ によるレバレッジ効果の評価など）を使う用途には NUTS、という使い分けが妥当である（\cref{tab:sys-roles}）。
  \item \textbf{並列化の方式は計測して選ぶ}。
    JAX の \code{vmap} によるベクトル化は、この問題では CPU でかえって遅く、1 デバイスでも 1 銘柄ずつ処理する方が 1.7 倍速かった（\cref{sec:sys-multi}）。
    計算の形（逐次的な代入が中心か、行列演算が中心か）とハードウェアによって最適な方式は変わる。
  \item \textbf{再現性は設計で確保する}。
    乱数のキーを銘柄と日付から決定的に作って保存し、ライブラリのバージョンを固定すれば、確率的な手法でも結果を後から再現できる（\cref{sec:sys-repro}）。
\end{enumerate}

\subsection{本稿の限界}\label{sec:conc-limitations}

本稿の結果は、次の限界の下で得られたものである。

\paragraph{データ}
実データは J-Quants の無料プランで取得できる約 2 年分（485 営業日）に限られた（\cref{sec:emp-data}）。
推定されたパラメータ（$\phi \approx 0.86$〜$0.92$、$\sigma \approx 0.31$〜$0.46$）は、長期のデータでの文献の値と比べて持続性が低く変動が大きく、
2025 年 4 月の急変動という 1 回の出来事の影響を強く受けている（\cref{sec:emp-full}）。
VaR のバックテストの検証期間も 235 日しかなく、とくに 1\% VaR の検定の検出力は低い（\cref{sec:emp-var}）。
また、日経平均株価と TOPIX の代わりに ETF を使っており、分配落ちなどの点で指数そのものとは異なる。
対象は日本の株式に限られ、為替・金利・コモディティなど他の資産クラスでは確かめていない。

\paragraph{比較の条件}
GARCH(1,1) との比較は、最尤推定の点推定（パラメータの不確実性を予測に入れない）と、SV モデルのベイズ予測分布との比較であり、
予測性能の差には、モデルの違いだけでなく推定の枠組みの違いも含まれる。
GARCH の非対称な拡張（GJR-GARCH \parencite{glosten1993}、EGARCH \parencite{nelson1991}など）とも比べていない（\cref{sec:emp-discussion}）。

\paragraph{正解役の NUTS}
合成データの復元実験（S1）の NUTS は、各連鎖 2,000 回で、200 回中 156 回でパラメータの $\hat R$ が 1.05 を超えた（\cref{sec:syn-recovery}）。
NUTS との細かい比較は長い連鎖の S2・R1b で行ったが、S1 の NUTS の被覆率などには、混合の不足による誤差が含まれている。

\paragraph{提案手法}
提案手法の系統的な差（$\sigma$ の過小、$\rho$ の縮小、パラメータの不確実性の過小評価）は、VaR の水準ではほとんど影響しなかったが、
本稿で評価していない用途（シナリオ生成、オプションの評価など）では問題になりうる。
また、本稿で扱ったのは 1 変量の SV モデルの三つの形（基本・レバレッジ・$t$ 誤差）だけであり、より複雑なモデルへの適用は確かめていない。

\paragraph{計算環境と判定の方法}
計算時間はすべて、WSL2 上の 1 台の CPU マシン（12 個の論理 CPU）で測った。
GPU や大規模なサーバでは、手法間の速さの比や並列化の効率は変わりうる。
また、本稿で使った ELBO の収束の判定は、ELBO の推定値の雑音に対して閾値が小さすぎ、収束までの時間の計測に偶然のばらつきを含んでいる（\cref{sec:sys-warm}）。
\cref{sec:syn-scaling}の「収束までの時間」は、この点を割り引いて読む必要がある。

\subsection{今後の課題}\label{sec:conc-future}

\subsubsection{変分族の改良}

\paragraph{非線形の依存を表す族}
提案手法に残る系統的な差の多くは、正規分布の族では表せない非線形の依存による。
レバレッジ SV の $\rho$ の縮小は、$h_{t+1}$ の条件付き平均が $e^{-h_t/2}$ を通じて $h_t$ に非線形に依存することによる（\cref{sec:fam-leverage}）。
$\mu$–$\phi$ のバナナ型の依存、短い系列での $\sigma$ の右に裾の長い事後分布も、$q(u)$ を正規分布としたことの限界である（\cref{sec:syn-recovery,sec:emp-multi}）。
これらを改善する方法として、正規化フロー \parencite{rezende2015,kingma2016}がある。
正規化フローは、単純な分布からのサンプルに、可逆で微分可能な変換を何段も重ねて、複雑な分布を表す方法である。
たとえば、大域パラメータ $u$（3〜4 次元）の分布だけをフローで表すのは計算量の点でも容易であり、$\mu$–$\phi$ の依存や $\sigma$ の非対称性の改善が期待できる。
$h$ の遷移を非線形にする（$h_{t+1}$ の条件付き平均を $h_t$ と $y_t$ の非線形関数にする）ことは、$O(T)$ の計算量を保ったまま実現できるかが鍵になる。

\paragraph{重要度重みによる補正}
VI の近似を提案分布として、重要度サンプリングで真の事後分布に補正する方法もある \parencite{tan2020}。
ただし、本稿では $\hat k$ が提案手法でも 0.7 を超えており（\cref{sec:syn-agreement}）、$T$ 次元の潜在変数全体での単純な重要度サンプリングは不安定になると予想される。
大域パラメータ $\theta$ についてだけ重みを計算する（$h$ は $q(h \mid \theta)$ で周辺化する）などの工夫が必要である。

\paragraph{VI で MCMC を速くする}
VI と MCMC は、対立するものではなく組み合わせることもできる。
たとえば、VI の結果を NUTS の初期値や質量行列（各変数の尺度と相関）に使えば、NUTS のウォームアップが短くなり、混合も改善する可能性がある。
本稿の運用案では、週次の NUTS による突き合わせを日次の VI の結果から始めることで、監査役の NUTS 自体を速く、かつ確実に収束させられるかもしれない。

\subsubsection{推定のアルゴリズムと運用}

\paragraph{雑音を考慮した収束判定と早期打ち切り}
\cref{sec:sys-warm}で見たように、ELBO の相対変化による収束の判定は、ELBO の推定値の雑音のために、ELBO が平らになった後は偶然に成立する。
ELBO の窓平均の差をその標準誤差と比べる判定、変分パラメータの変化の大きさによる判定、あるいは勾配の大きさによる判定など、雑音を考慮した判定を設計し、
最適化を早めに打ち切れれば、毎回ゼロからの推定の時間はさらに短くなる。
warm start のステップ数（本稿では 1,000〜2,000 が妥当であった）も、日ごとに適応的に決められる可能性がある。

\paragraph{GPU と単精度}
本稿では GPU で計測していない。
提案手法の中心は逐次的な三重対角の代入であり、1 系列の計算の中で並列化できる部分は少ないが、多数の銘柄をまとめて計算すれば GPU の並列性を生かせる可能性がある。
その場合、CPU での vmap の結果（\cref{sec:sys-multi}）が GPU でも当てはまるか、単精度で十分な精度が出るかを確かめる必要がある。
並列の前進・後退代入（並列スキャン）などのアルゴリズムの工夫も考えられる。

\paragraph{償却推論}
数千〜数万の系列を扱う場合には、系列ごとに変分パラメータを最適化するのではなく、データから変分パラメータを出力するニューラルネットワーク（推論ネットワーク）を学習しておく償却推論 \parencite{archer2015,krishnan2017}も選択肢になる。
新しい系列や新しい日の推定は、ネットワークに 1 回データを通すだけで済む。
ただし、償却による近似の誤差が加わるので、本稿のような NUTS との突き合わせによる検証がより重要になる。

\paragraph{銘柄間の情報の共有}
本稿では銘柄ごとに独立に推定したが、32 銘柄の $\phi$ や $\sigma$ は互いに似た範囲にあった（\cref{sec:emp-multi}）。
銘柄のパラメータが共通の分布から生成されるとする階層モデルを使えば、データの短い銘柄（新規上場など）でも、他の銘柄の情報を借りて安定した推定ができる。
提案手法の $q(u)$ を銘柄間で結合すれば、VI でも扱える。

\subsubsection{モデルの拡張}

\paragraph{多変量 SV とポートフォリオのリスク}
実務の VaR は、個別の資産ではなくポートフォリオについて計算することが多い。
そのためには、複数の資産のボラティリティと相関の動きを同時に扱う多変量 SV モデル \parencite{asai2006}、
とくに少数の共通因子でボラティリティの動きを説明するファクター SV モデル \parencite{chib2006}への拡張が必要である。
潜在変数の数は資産数 $\times T$ に増えるが、時間方向の三重対角の構造は保たれるので、提案手法の考え方（条件付きの構造化）を拡張できる可能性がある。
多変量の SV やファクター SV に対する VI の研究 \parencite{gunawan2021,chan2022,quiroz2023}も進んでいる。

\paragraph{ジャンプ}
2025 年 4 月のような急変動は、ボラティリティの連続的な変化だけでは説明しきれない可能性がある。
リターンやボラティリティにジャンプを加えた SV モデル \parencite{eraker2003}は、急変動の扱いを改善すると期待される。
ジャンプは離散的な潜在変数であり、VI での扱いには工夫が必要である。

\paragraph{実現ボラティリティの利用}
日中の高頻度データから計算した実現ボラティリティを、日次リターンと同時に使う SV モデル（実現 SV モデル）\parencite{takahashi2009}は、
ボラティリティの推定と予測の精度を大きく改善することが知られている。
日中のデータが使える場合には、観測方程式に実現ボラティリティを加えるだけで、提案手法の構造（三重対角の精度行列）はそのまま保たれる。
ボラティリティについての情報が増える分、$h_t$ の事後分布の幅は狭くなり、VI による近似もより正確になると予想される。

\paragraph{期待ショートフォール}
FRTB では、市場リスクの所要自己資本の計算に、VaR に代えて 97.5\% の期待ショートフォール（ES）が使われる \parencite{bcbs2019}。
SV モデルの予測分布は混合分布として明示的に計算できるので（\cref{sec:model-predictive}）、ES の計算は容易である。
ES のバックテストの方法とあわせて、評価を拡張する必要がある。

\subsubsection{実証の拡張}

\begin{itemize}
  \item \textbf{長期のデータ}：J-Quants の有料プラン（5〜10 年分、TOPIX 本体を含む）などを使い、より長い期間・複数の市場局面で推定と VaR の検証を行う。
    長期のデータでは $\phi$ が高くなると予想され、合成データの結果からは、平均場・構造化の失敗はより顕著になり、提案手法の優位はより明確になると考えられる。
  \item \textbf{他の資産クラス}：為替・金利・コモディティなど、ボラティリティの性質（持続性、非対称性）が異なる資産でも確かめる。
  \item \textbf{比較の対象}：GJR-GARCH \parencite{glosten1993}や EGARCH \parencite{nelson1991}などの非対称な GARCH、パラメータの不確実性を入れたベイズ GARCH とも比べる。
  \item \textbf{正解役の強化}：合成データの復元実験（S1）の NUTS を長い連鎖で回し直し、NUTS 自身の被覆率の誤差を取り除く。
\end{itemize}

\subsubsection{運用への展開}

本稿の結果は、研究用の実験環境で得られたものである。
実際のシステムに組み込む前には、次の段階を踏むことを提案する。

\begin{enumerate}
  \item \textbf{並行運用（シャドー運用）}：既存のリスク計算と並行して、提案手法による日次の VaR を数か月間出し続け、\cref{sec:sys-monitor}の監視を実際のデータで試す。
    監視の閾値（推定値の日次の変化、NUTS との差の範囲）は、この期間のデータで調整する。
  \item \textbf{モデル・リスク管理の文書化}：金融庁の「モデル・リスク管理に関する原則」\parencite{fsa2021mrm}などに沿って、
    モデルと推定方法の前提・限界（本稿の\cref{sec:conc-limitations}）、検証の方法（NUTS との突き合わせ、バックテスト）、監視の手順を文書にまとめ、独立した検証を受ける。
  \item \textbf{本番環境での計測}：並列化の方式、デバイスの数、warm start のステップ数を、本番の計算機で計測して決める（\cref{sec:sys-multi}）。
\end{enumerate}

\subsection{おわりに}\label{sec:conc-closing}

変分推論は「速いが不正確」と言われることが多い。
本稿の結果は、それが半分だけ正しいことを示している。
汎用的な変分族は、SV モデルでは不正確どころか、モデルの解釈を変えてしまうほど大きく外れた。
しかし、事後分布の構造を理解し、それに合わせて変分族を設計すれば、MCMC にほぼ匹敵する精度を、実務の日次処理に十分な速さで得られる。
その一方で、近似が残す系統的な差を把握し、MCMC による定期的な検証と監視の仕組みを組み合わせることが、信頼できるシステムの条件である。
本稿が、ベイズ推定を金融機関のシステムに組み込む際の、一つの具体的な設計例として役立てば幸いである。
