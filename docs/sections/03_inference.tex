\section{ベイズ推定と変分推論の基礎}\label{sec:inference}

本章では、SV モデルの事後分布\cref{eq:sv-posterior}を扱う二つの方法、マルコフ連鎖モンテカルロ法（MCMC）と変分推論（VI）の基礎を説明する。
本稿の読者の多くにとって、これらはなじみの薄い道具であると思われるので、実装の見通しが持てる程度まで、導出を省略せずに述べる。
\cref{sec:inf-bayes}でベイズ推定の枠組みを確認し、\cref{sec:inf-mcmc}で本稿の「正解」として使う NUTS を説明する。
\cref{sec:inf-vi}で VI の考え方と、それが不確実性を過小評価する理由を述べ、SV モデルで平均場近似が失敗する仕組みを数値で示す。
\cref{sec:inf-reparam,sec:inf-advi}で、VI を勾配法で解くための再パラメータ化勾配と、それを自動化した ADVI を説明する。
\cref{sec:inf-diagnostics}で VI の収束判定と当てはまりの診断を、\cref{sec:inf-compare}で MCMC と VI の比較をまとめる。
SV モデルに合わせた変分族の設計は、次の\cref{sec:family}で扱う。

\subsection{ベイズ推定の枠組み}\label{sec:inf-bayes}

\cref{sec:model-likelihood}で見たように、SV モデルでは、パラメータ $\theta$ と潜在変数 $h_{1:T}$ をまとめた未知数
$z = (\theta, h_{1:T})$ の事後分布
\[
  p(z \mid y) = \frac{p(y, z)}{p(y)}, \qquad p(y, z) = p(\theta)\, p(h_{1:T} \mid \theta)\, p(y_{1:T} \mid h_{1:T}, \theta), \qquad p(y) = \int p(y, z)\, dz
\]
を求めることが推定の目標になる（以下、紛れがなければ $y_{1:T}$ を $y$ と書く）。
分子の同時密度 $p(y, z)$ は初等関数の積なので、任意の $z$ で計算できる。
一方、分母の正規化定数 $p(y)$（周辺尤度、エビデンス）は $T + k$ 次元の積分であり、計算できない。
「分子は計算できるが分母は計算できない」という状況で事後分布をどう扱うかが、ベイズ計算の中心的な問題である。

実務で必要になるのは、事後分布そのものではなく、その要約である。
例えば、パラメータの事後平均 $\E[\theta \mid y]$ と事後標準偏差、各日の対数ボラティリティ $h_t$ の事後平均と 95\% 信用区間（事後分布の 2.5\% 点と 97.5\% 点の間）、
そして\cref{sec:model-predictive}の予測分布などである。
これらはすべて、ある関数 $f$ の事後期待値
\[
  \E[f(z) \mid y] = \int f(z)\, p(z \mid y)\, dz
\]
として書ける（分位点も、指示関数の期待値を通じて同様に扱える）。
事後分布からのサンプル $z^{(1)}, \dots, z^{(S)}$ があれば、これは標本平均
\[
  \E[f(z) \mid y] \approx \frac{1}{S} \sum_{s=1}^{S} f(z^{(s)})
\]
で近似できる（モンテカルロ積分）。
サンプルが互いに独立なら、近似の誤差（標準誤差）は $\sqrt{\mathrm{Var}[f(z) \mid y] / S}$ であり、次元 $T$ によらずサンプル数の平方根に反比例して小さくなる。
サンプルが互いに相関している場合は、$S$ の代わりに、相関を考慮した実質的なサンプル数である\textbf{有効サンプルサイズ（ESS）}を使う。
MCMC と VI は、どちらも最終的にはこうしたサンプルを作る方法であり、違いは「サンプルがどの分布から、どのような計算で得られるか」にある。

SV モデルをベイズ推定する利点は、\cref{sec:intro-models}で述べたボラティリティの不確実性に加えて、\textbf{パラメータの不確実性を予測に反映できる}点にある。
本稿の実データのように系列が 2 年程度と短いと、持続性 $\phi$ やボラティリティの変動の大きさ $\sigma$ の推定には大きな不確実性が残る（\cref{sec:empirical}では $\phi$ の事後標準偏差が 0.05 程度）。
最尤推定値を一つ選んで予測に使うと、この不確実性は予測分布に現れず、予測分布の裾が薄くなりがちである。
ベイズ推定では、\cref{sec:model-predictive}のように事後分布全体で予測分布を平均するので、パラメータの不確実性が予測分布の裾の厚さとして自然に反映される。
逆に言えば、近似推論が事後分布の広がりを過小評価すると、この利点が失われ、VaR が楽観的になる。
本稿で事後分布の「広がり」の再現を重視するのはこのためである。

\subsection{マルコフ連鎖モンテカルロ法と NUTS}\label{sec:inf-mcmc}

\paragraph{MCMC の考え方}
MCMC は、事後分布 $p(z \mid y)$ を定常分布に持つマルコフ連鎖 $z^{(0)} \to z^{(1)} \to z^{(2)} \to \cdots$ を構成し、
十分に長く走らせた後の状態を事後分布からのサンプルとして使う方法である。
代表的なメトロポリス・ヘイスティングス法 \parencite{metropolis1953,hastings1970} では、現在の状態 $z$ から提案分布 $r(z' \mid z)$ に従って候補 $z'$ を作り、確率
\[
  \alpha(z, z') = \min\left\{1,\ \frac{p(y, z')\, r(z \mid z')}{p(y, z)\, r(z' \mid z)}\right\}
\]
で受理する（棄却したら $z$ にとどまる）。
受理確率に現れるのは同時密度 $p(y, z)$ の\textbf{比}だけなので、計算できない正規化定数 $p(y)$ は打ち消し合い、不要になる。
これが MCMC がベイズ計算で広く使われる理由である。

最も単純な提案分布は、現在の点のまわりにランダムに一歩動く「ランダムウォーク」である。
しかし次元が高いと、ランダムな方向への一歩は事後分布の確率の高い領域から外れやすく、受理されるためには歩幅を非常に小さくしなければならない。
その結果、連鎖はゆっくりとしか動かず、隣り合うサンプルが強く相関して、ESS が極端に小さくなる。
SV モデルの事後分布は数百〜数千次元で、しかも変数どうしが強く相関している（\cref{sec:model-structure}）ので、ランダムウォークでは実用にならない。
\textcite{jacquier1994} の $h_t$ を一つずつ更新する方法や、\textcite{kim1998} の混合正規近似による一括更新は、この問題を SV モデルに特化した工夫で乗り越えたものである。

\paragraph{ハミルトニアン・モンテカルロ法（HMC）}
汎用的な解決策が、対数事後密度の勾配を使って遠くまで効率的に移動するハミルトニアン・モンテカルロ法（HMC）である \parencite{duane1987,neal2011,betancourt2017}。
HMC では、位置 $z$ に加えて同じ次元の運動量 $p \sim \Normal(0, M)$ を導入し、ポテンシャルエネルギー $U(z) = -\log p(y, z)$ と運動エネルギー $\frac{1}{2} p^\top M^{-1} p$ の和であるハミルトニアン
\[
  H(z, p) = -\log p(y, z) + \frac{1}{2} p^\top M^{-1} p
\]
に従う物理系の運動をシミュレーションする。
ハミルトン方程式に従う運動は $H$ を保存するので、確率の高い領域（ポテンシャルの谷）に沿って、遠くまで移動しても受理確率が高く保たれる。
運動は「リープフロッグ法」で離散化する。歩幅 $\varepsilon$ の 1 ステップは
\[
  p \leftarrow p + \frac{\varepsilon}{2} \nabla_z \log p(y, z), \qquad
  z \leftarrow z + \varepsilon\, M^{-1} p, \qquad
  p \leftarrow p + \frac{\varepsilon}{2} \nabla_z \log p(y, z)
\]
であり、これを $L$ 回繰り返した終点を候補とする。
離散化の誤差で $H$ がわずかに変わる分は、メトロポリス・ヘイスティングスの受理判定で補正するので、得られるサンプルは正確に事後分布に従う。
1 回の更新に $L$ 回の勾配計算が必要だが、SV モデルでは対数同時密度の勾配は自動微分によって $O(T)$ で計算できる。

\paragraph{NUTS}
HMC の性能は歩幅 $\varepsilon$、ステップ数 $L$、質量行列 $M$ の選び方に強く依存する。
No-U-Turn Sampler（NUTS）\parencite{hoffman2014} は、軌道が折り返し始めた（U ターンした）ところで自動的に延長を止めることでステップ数 $L$ を毎回適応的に決め、
さらにウォームアップ（burn-in）期間中に、受理確率が目標値になるよう歩幅を調整し、事後分布の各方向の広がりに合わせて質量行列を推定する。
これにより、利用者はモデルの対数密度を書くだけでよく、調整パラメータをほとんど意識せずに使える。
本稿では NumPyro \parencite{phan2019} の NUTS を、目標受理率 0.9、対角の質量行列（NumPyro の既定）、木の深さの上限 10（1 回の更新あたり最大 $2^{10} - 1 = 1{,}023$ 回の勾配計算）で使う。
パラメータ化は中心化とし（\cref{sec:model-param}）、制約のあるパラメータは\cref{sec:inf-advi}と同じ変換で無制約空間に写してからサンプリングする。

\paragraph{SV モデルで NUTS が遅い理由}
NUTS は汎用的で強力だが、SV モデルの事後分布は NUTS にとっても扱いにくい形をしている。
\begin{itemize}
  \item \textbf{次元が高く、変数が強く相関している}：$h_{1:T}$ の事後分布は隣り合う日の相関が 0.9 を超える（\cref{tab:meanfield-gap}）。対角の質量行列ではこの相関を吸収できず、軌道が長くなる。
  \item \textbf{場所によって曲率が大きく異なる}：$\sigma$ が小さい領域では $h$ の経路は滑らかでなければならず（精度行列が $1/\sigma^2$ に比例）、事後分布は細い谷になる。$\sigma$ が大きい領域では谷が広がる。
    このような「漏斗」型の形状では、一つの歩幅で谷の細い部分と広い部分の両方をうまく探索できず、歩幅が細い部分に合わせて小さくなる。
    $\sigma$ の混合が悪いという\cref{sec:intro-mcmc}の観察は、この形状によるものである。
  \item \textbf{$\mu$ と $\phi$ のバナナ型の依存}（\cref{sec:model-structure}）も、同様に探索を難しくする。
\end{itemize}
その結果、1 回の更新に数百回の勾配計算が必要になることも珍しくなく、しかも得られるサンプルの自己相関は高い。
本稿の計算時間の実験（\cref{sec:synthetic}）で、$T = 10{,}000$ の NUTS が 548 秒かかっても $\theta$ の ESS が 14 にとどまったのはこのためである。

\paragraph{収束の診断}
MCMC の結果を使う前には、連鎖が定常分布に到達し、十分に混合しているかを確認する必要がある。本稿では次の三つを見る。
\begin{itemize}
  \item \textbf{$\hat R$（ポテンシャル・スケール縮小係数）}：異なる初期値から始めた複数の連鎖（本稿では 4 本）について、連鎖間の分散と連鎖内の分散を比べる指標である \parencite{gelman1992}。
    各連鎖を前半と後半に分けて計算する split-$\hat R$ \parencite{gelman2013} を使う。すべての連鎖が同じ分布を探索していれば 1 に近く、1 より大きいほど連鎖どうしが食い違っている。
    本稿では目安として 1.05 を使う。より厳しい 1.01 を推奨する提案もある \parencite{vehtari2021}。
  \item \textbf{有効サンプルサイズ（ESS）}：自己相関を考慮した実質的なサンプル数。事後平均の推定に 100〜400 程度は欲しい、というのが一般的な目安である。
  \item \textbf{発散（divergence）}：リープフロッグ法の離散化誤差が爆発した回数。漏斗のような曲率の急な領域を探索できていない兆候である。
\end{itemize}
$\hat R$ を意味のある診断にするには、連鎖ごとに異なる初期値から始める必要がある。
本稿では、共通の初期値（\cref{app:settings}）を無制約空間で標準偏差 0.1 だけ連鎖ごとにずらして始め、4 本の連鎖を CPU の 4 つのデバイスで並列に実行する。
反復数は、合成データの復元実験と実データでウォームアップ・サンプリング各 2,000、計算時間の実験で各 1,000、
「正解」として使う NUTS（\cref{sec:synthetic}の一致度の実験）ではウォームアップ 2,000 の後に 32,000 回更新して 8 回に 1 回を保存する（各連鎖 4,000 サンプル）。
最後の設定で $\hat R \leq 1.003$、$\sigma$ の ESS 約 800 を得ており、これを事後分布の「正解」とみなす。

\subsection{変分推論}\label{sec:inf-vi}

\paragraph{KL 情報量と ELBO}
変分推論（VI）は、事後分布 $p(z \mid y)$ を、計算しやすい分布の族 $\mathcal{Q} = \{q_\lambda(z)\}$ の中で最も近い分布で近似する \parencite{blei2017}。
$\lambda$ は分布を指定するパラメータで、\textbf{変分パラメータ}と呼ぶ（例えば正規分布の族なら平均と共分散）。
分布の近さは、カルバック・ライブラー情報量
\[
  \KL(q \,\|\, p(\cdot \mid y)) = \int q(z) \log \frac{q(z)}{p(z \mid y)}\, dz = \E_q[\log q(z)] - \E_q[\log p(z \mid y)]
\]
で測る。KL 情報量は常に 0 以上で、$q$ と $p$ が一致するときに限り 0 になる。
しかしこの式には計算できない $p(z \mid y) = p(y, z) / p(y)$ が含まれているので、このままでは最小化できない。
そこで $\log p(z \mid y) = \log p(y, z) - \log p(y)$ を代入すると、
\begin{equation}
  \KL(q \,\|\, p(\cdot \mid y)) = \E_q[\log q(z)] - \E_q[\log p(y, z)] + \log p(y)
\end{equation}
となる。$\log p(y)$ は $q$ によらない定数なので、移項して
\begin{equation}
  \log p(y) = \underbrace{\E_q[\log p(y, z)] - \E_q[\log q(z)]}_{\ELBO(q)} + \KL(q \,\|\, p(\cdot \mid y))
  \label{eq:elbo-identity}
\end{equation}
を得る。右辺第 1 項を\textbf{証拠下界（evidence lower bound, ELBO）}と呼ぶ。
KL 情報量が 0 以上であることから $\ELBO(q) \leq \log p(y)$ であり、ELBO は対数周辺尤度の下界になっている（名前の由来）。
左辺は $q$ によらないので、\textbf{ELBO を最大化することと、KL 情報量を最小化することは同値}である。
ELBO は計算できる $p(y, z)$ と、自分で選んだ $q$ だけで書けているので、最適化の目的関数として使える。

ELBO はさらに
\begin{equation}
  \ELBO(q) = \E_q[\log p(y, z)] + \mathcal{H}[q], \qquad \mathcal{H}[q] = -\E_q[\log q(z)]
  \label{eq:elbo}
\end{equation}
と書ける。第 1 項は、$q$ が同時密度の高い（データをよく説明し、事前分布とも整合する）領域に確率を置くほど大きくなる「当てはまり」の項である。
第 2 項はエントロピーで、$q$ が広がっているほど大きくなる。
第 1 項だけを最大化すると $q$ は同時密度の最大点（MAP 推定値）に縮退してしまうが、エントロピーの項がそれを防ぎ、$q$ を適度に広げる。
VI は、この二つの項のつり合いで事後分布の位置と広がりを決める方法である。

\paragraph{$\KL(q \,\|\, p)$ の性質：不確実性の過小評価}
KL 情報量は非対称であり、$\KL(q \,\|\, p)$ と $\KL(p \,\|\, q)$ は異なる。
VI が最小化する $\KL(q \,\|\, p)$ は $q$ による期待値なので、$p$ の確率が小さいところに $q$ が確率を置くと $\log(q/p)$ が大きくなり、強く罰せられる。
逆に、$p$ の確率が大きいところに $q$ が確率を置かなくても、ほとんど罰せられない。
このため $q$ は、$p$ の確率の高い領域の内側に収まろうとし（ゼロ強制、あるいはモード追従と呼ばれる性質）、$p$ の裾を切り捨てる。
その結果、族 $\mathcal{Q}$ が $p$ を正確に表せないとき、VI は事後分布の広がりを過小評価しやすい \parencite{blei2017}。

この性質は、正規分布の例で正確に確かめられる \parencite{bishop2006}。
真の分布が精度行列 $\Lambda$（共分散行列 $\Sigma = \Lambda^{-1}$）の多変量正規分布 $\Normal(m, \Lambda^{-1})$ であるとし、
各変数を互いに独立とする\textbf{平均場近似} $q(z) = \prod_i q_i(z_i)$ で近似する。
このとき KL 情報量を最小にする $q$ は
\[
  q_i(z_i) = \Normal\!\left(z_i \mid m_i,\ 1 / \Lambda_{ii}\right)
\]
であり、平均は正しく求まるが、分散は真の周辺分散 $\Sigma_{ii} = (\Lambda^{-1})_{ii}$ ではなく $1/\Lambda_{ii}$ になる。
$1/\Lambda_{ii}$ は「他のすべての変数を固定したときの $z_i$ の条件付き分散」であり、一般に $1/\Lambda_{ii} \leq (\Lambda^{-1})_{ii}$ が成り立つ（等号は $z_i$ が他と無相関のときに限る）。
二変数で相関係数が $r$ なら、平均場の分散は真の分散の $1 - r^2$ 倍になる。
平均場近似は、他の変数の不確実性を「固定されたもの」として扱い、それが $z_i$ に波及する分を無視するのである。
このときの KL 情報量の最小値は
\begin{equation}
  \min_{q:\,\text{平均場}} \KL(q \,\|\, p) = \frac{1}{2}\left(\sum_i \log \Lambda_{ii} - \log \det \Lambda\right) \;\geq\; 0
  \label{eq:mf-kl}
\end{equation}
であり、変数間の相関が強いほど大きくなる（アダマールの不等式により非負で、$\Lambda$ が対角のときに限り 0）。

\paragraph{SV モデルでの平均場近似：なぜ $\phi$ が崩れるのか}
この結果を SV モデルに当てはめてみる。
$\theta$ を固定したときの $h_{1:T}$ の事後分布は、\cref{eq:laplace-precision}のとおり精度行列 $Q_{\mathrm{AR}}(\phi, \sigma) + \diag(\cdot)$ の正規分布でよく近似できる。
対角に加わる観測の情報は、モデルのもとでの期待値で $\E[y_t^2 e^{-h_t}]/2 = 1/2$（観測 1 つあたりの期待フィッシャー情報）なので、
ここでは $\Lambda = Q_{\mathrm{AR}}(\phi, \sigma) + \frac{1}{2} I$ として、隣接日の事後相関、平均場の標準偏差の真の値に対する比、KL の最小値\cref{eq:mf-kl}を計算した（\cref{tab:meanfield-gap}、$T = 1{,}000$）。

持続性の高いシナリオ（$\phi = 0.97$〜$0.99$）では、隣り合う日の $h_t$ の事後相関は約 0.9 に達し、平均場の標準偏差は真の値の 1/3〜1/4 にまで縮む。
これは「平均場近似は分散を過小評価する」という教科書的な結果の SV 版である。
しかし、より深刻なのは KL の最小値の方である。
$\phi = 0.97$〜$0.99$ では、平均場近似は、どれほどうまく最適化しても真の事後分布から 300 nats（自然対数の単位）程度離れたところにしか到達できない。
一方、$\phi$ が 0 に近ければ $h_t$ どうしはほぼ独立になり、平均場近似はほぼ正確（KL の最小値 1 nat 程度）になる。

ここで、$\theta$ も変分推論で推定する場合を考える。
$q(z) = q(\theta)\, q(h)$ と分け、話を簡単にするために $\theta$ をある値に固定して考える（$q(\theta)$ の広がりとエントロピーの寄与を除く）と、ELBO は
\[
  \ELBO \approx \log p(y \mid \theta) + \log p(\theta) - \KL\!\left(q(h) \,\|\, p(h \mid y, \theta)\right)
\]
と書ける。最適化は、尤度 $\log p(y \mid \theta)$ が大きいことと、その $\theta$ のもとで $q(h)$ が事後分布をうまく近似できること（KL が小さいこと）の両方を求める。
平均場近似では後者の KL が $\phi$ とともに急激に大きくなるので、\textbf{ELBO は尤度の高い $\phi \approx 0.98$ よりも、平均場近似が正確になる小さい $\phi$ を好む}。
\cref{tab:meanfield-laplace}は、\cref{sec:synthetic}の一致度の実験で使った合成データ（高持続、$T = 1{,}000$）について、ラプラス近似によってこれを確認したものである。
NUTS の事後平均では、尤度は平均場 VI の推定値より 46 nats 高いが、平均場近似の KL の最小値が 304 nats もあるため、両者の差し引きでは平均場 VI の推定値の方が 250 nats 以上有利になる。
平均場 VI が $\phi$ を 0.05 程度にまで崩してしまうのは、最適化の失敗ではなく、\textbf{ELBO という目的関数そのものがその解を好む}からである。
時系列モデルの変分推論で、パラメータの推定値が「近似が正確になる値」の方向に偏るこの現象は、\textcite{turner2011} が指摘しているものと同じである。

変分族は、事後分布の主要な依存（ここでは $h_t$ どうしの時間方向の相関）を表現できなければ、不確実性を過小評価するだけでなく、パラメータの推定そのものを偏らせる。
同じ理屈で、$\theta$ と $h$ を独立とする族は、$\sigma$ と $h$ の滑らかさの依存（\cref{sec:model-structure}）を表現できないために、$\sigma$ の推定を偏らせ、その不確実性を過小評価する（\cref{sec:family,sec:synthetic}）。

\subsection{再パラメータ化勾配と確率的最適化}\label{sec:inf-reparam}

ELBO \cref{eq:elbo}を変分パラメータ $\lambda$ について最大化するには、その勾配 $\nabla_\lambda \ELBO(\lambda)$ が必要である。
しかし ELBO は $q_\lambda$ についての期待値であり、期待値をとる分布そのものが $\lambda$ に依存するので、そのままでは期待値の中で微分できない。

一つの方法は、$\nabla_\lambda q_\lambda = q_\lambda \nabla_\lambda \log q_\lambda$ という恒等式を使って勾配を期待値の形に直すスコア関数推定量である。
これはどんな $q$ にも使えるが、勾配の推定値の分散が大きく、高次元では多数のサンプルや分散低減の工夫が必要になる。

本稿で使うのは、\textbf{再パラメータ化}による推定量である \parencite{kingma2014}。
$q_\lambda$ からのサンプルを、$\lambda$ によらない分布からの乱数 $\epsilon$ の変換として
\[
  z = T_\lambda(\epsilon), \qquad \epsilon \sim \Normal(0, I)
\]
と書けるとする。正規分布 $\Normal(m, C C^\top)$ なら $T_\lambda(\epsilon) = m + C\epsilon$（$C$ は共分散行列のコレスキー因子などの行列）である。
すると期待値は $\epsilon$ の分布についての期待値に書き直せて、
\[
  \ELBO(\lambda) = \E_{\epsilon}\!\left[\log p\!\left(y, T_\lambda(\epsilon)\right)\right] + \mathcal{H}[q_\lambda]
\]
となる。今度は期待値をとる分布が $\lambda$ によらないので、微分を期待値の中に入れられ、
\[
  \nabla_\lambda \ELBO(\lambda) = \E_{\epsilon}\!\left[ \left(\frac{\partial T_\lambda(\epsilon)}{\partial \lambda}\right)^{\!\top} \nabla_z \log p(y, z)\Big|_{z = T_\lambda(\epsilon)} \right] + \nabla_\lambda \mathcal{H}[q_\lambda]
\]
を得る。期待値は $M$ 個の乱数 $\epsilon^{(1)}, \dots, \epsilon^{(M)}$ による標本平均で推定する。
この推定値は不偏であり（期待値が真の勾配に等しい）、対数同時密度の勾配 $\nabla_z \log p(y, z)$ の情報を直接使うので、スコア関数推定量より分散がはるかに小さい。
実装上は、「乱数 $\epsilon$ を生成し、$z = T_\lambda(\epsilon)$ を計算し、$\log p(y, z)$ を評価して平均をとる」という ELBO の推定値の計算を書けば、
$\lambda$ についての勾配は自動微分がすべて計算してくれる。

正規分布の族では、エントロピーは解析的に
\[
  \mathcal{H}[\Normal(m, C C^\top)] = \frac{d}{2}\left(1 + \log 2\pi\right) + \log \lvert \det C \rvert
\]
と書ける（$d$ は次元）。$C$ が三角行列なら $\log \lvert\det C\rvert = \sum_i \log \lvert C_{ii} \rvert$ であり、計算は対角成分の和で済む。
本稿の実装では、対角成分を指数関数で表して正値を保証している（\code{advi.py} の \code{\_tril}）。
\cref{sec:family}の条件付き構造化族のようにエントロピーの一部が解析的に書けない場合も、その部分をサンプルで推定すれば同じ枠組みで扱える。

こうして得られる勾配はノイズを含むので、最適化は確率的勾配法 \parencite{robbins1951} で行う。
本稿では、勾配の 1 次・2 次のモーメントの移動平均でパラメータごとに歩幅を調整する Adam \parencite{kingma2015} を使い、
学習率を 0.01 から始めて最終ステップで 0.001 になるよう指数的に減衰させる。
1 ステップあたりのモンテカルロサンプル数は $M = 4$、ステップ数は 10,000 とする（一致度の実験では 20,000）。
学習率を徐々に下げるのは、最適化の後半で勾配のノイズによる変分パラメータの揺れを抑えるためである。
これらの設定への感度は\cref{app:settings}で確認しており、提案手法の結果は $M \in \{1, 4, 16\}$、学習率 $\in \{0.003, 0.01, 0.03\}$ でほとんど変わらない。

\subsection{自動微分変分推論（ADVI）}\label{sec:inf-advi}

再パラメータ化勾配では $z = m + C\epsilon$ のような正規分布の変換を使うので、$z$ は実数全体の値をとりうる。
しかし SV モデルのパラメータには制約がある（$\sigma > 0$、$-1 < \phi < 1$ など）。
自動微分変分推論（ADVI）\parencite{kucukelbir2017} は、制約のあるパラメータをまず無制約の実数に写し、その空間で正規分布の族を当てはめることで、この問題を一般的に解決する。

本稿では、無制約の変数 $u$ から元のパラメータへの変換を次のように定める（\code{logdensity.py} の \code{constrain}）。
\[
  \mu = u_\mu, \qquad
  \phi = \tanh(u_\phi), \qquad
  \sigma = \exp(u_\sigma), \qquad
  \rho = \tanh(u_\rho), \qquad
  \nu = 2 + \exp(u_\nu).
\]
変数変換をすると密度にはヤコビアン（変換の微分の絶対値）が掛かるので、無制約空間での対数同時密度は
\begin{equation}
  \log \tilde p(y, u, h) = \log p\!\left(y, \theta(u), h\right) + \log(1 - \phi^2) + \log \sigma \;\Big[\, + \log(1 - \rho^2) \,\Big] \;\Big[\, + \log(\nu - 2) \,\Big]
  \label{eq:advi-jacobian}
\end{equation}
となる（角括弧の項はそれぞれレバレッジ SV、$t$ 誤差の SV の場合のみ。$d\tanh(u)/du = 1 - \tanh^2(u)$、$d e^u/du = e^u$ による）。
このヤコビアンの項を忘れると、無制約空間で別の分布を近似することになり、推定が偏る。
潜在変数 $h_t$ はもともと実数なので変換しない（非中心化パラメータ化では $x_t$ を使う。\cref{sec:model-param}）。

ADVI では、この無制約空間の $z = (u, h)$ に正規分布の族（またはその構造を制限したもの）を当てはめ、ELBO
\[
  \ELBO(\lambda) = \E_{q_\lambda}\!\left[\log \tilde p(y, u, h)\right] + \mathcal{H}[q_\lambda]
\]
を再パラメータ化勾配で最大化する。
無制約空間で正規分布であっても、元の空間に戻すと正規分布ではない。
例えば $u_\sigma$ が正規分布なら $\sigma$ は対数正規分布であり、右に裾を引いた非対称な形を表現できる。
推定後は、$q$ から $u$ をサンプルして元の空間に変換し、事後平均や信用区間を計算する。
$\log p(y)$ は変数変換によって変わらないので、ELBO の値は無制約空間で計算しても元の空間と同じ意味を持つ。

\paragraph{実装}
本稿では ADVI を JAX \parencite{bradbury2018} で自前実装した（\code{src/sv\_vi/advi.py}。抜粋を\cref{app:code}に示す）。
JAX を使うと、ELBO の推定値を計算する関数を NumPy に近い書き方で書くだけで、自動微分（\code{jax.grad}）によって勾配が得られ、
さらに JIT コンパイル（\code{jax.jit}）によって CPU 向けの高速な機械語に変換される。
本稿の実装では、10,000 ステップの最適化ループ全体を \code{jax.lax.scan} で書き、ループ全体を 1 回のコンパイルで一つの関数にしている。
Python のループで 1 ステップずつ関数を呼ぶ場合に比べて、呼び出しのオーバーヘッドがなくなり、また最適化全体が入力（データと乱数のシード）の純粋な関数になるので、
同じ入力からは常に同じ結果が得られる（再現性）。
この「1 系列の推定 = 1 つの純粋関数」という形は、\cref{sec:system}で多銘柄の推定を並列化するときにも、そのまま利用できる。

比較のため、確率的プログラミング言語 NumPyro の確率的変分推論（SVI）も使う。
NumPyro では、モデルを確率的プログラムとして書き、既製の「自動ガイド」（\code{AutoNormal}：平均場、\code{AutoLowRankMultivariateNormal}：低ランク＋対角、\code{AutoMultivariateNormal}：フルランク）を選ぶだけで ADVI を実行できる。
NumPyro の SVI には、自前実装と同じ ELBO・同じ最適化の設定（Adam、学習率スケジュール、$M = 4$）を使う。
自作の変分族（\cref{sec:family}の構造化族）も NumPyro のガイドとして実装し、自前実装と同じ結果になることを確認している（\cref{sec:synthetic}）。

\subsection{VI の収束判定と当てはまりの診断}\label{sec:inf-diagnostics}

\paragraph{ELBO の推移による収束判定}
VI は最適化なので、収束の判定は目的関数である ELBO の推移を見ればよい。
ただし ELBO の推定値はモンテカルロ誤差を含んで揺れるので、1 ステップごとの変化ではなく、一定の窓の平均の変化で判定する。
本稿では、200 ステップごとの ELBO の推定値の平均を計算し、その相対変化が $10^{-4}$ を下回った最初の時点を「収束したステップ」とする（\code{diagnostics.py} の \code{convergence\_step}）。
本稿の実験では、最適化自体は常に決められたステップ数（10,000 など）だけ実行し、収束したステップは「収束までにどれだけかかったか」を報告するためだけに使う。
運用では、この判定で早期に打ち切ることもできる（\cref{sec:system}）。

\paragraph{ELBO による変分族の比較}
\cref{eq:elbo-identity}より、同じモデル・同じデータに対しては $\log p(y)$ が共通なので、
\textbf{二つの変分族の ELBO の差は、そのまま事後分布への KL 情報量の差}になる。
したがって、ELBO が大きい族ほど事後分布に近い、と言える。
変数変換は $\log p(y)$ を変えないので、パラメータ化（中心化・非中心化）が異なる族どうしでも ELBO は比較できる。
ただし ELBO が分かるのは「どちらがより近いか」であって、「どの程度近いか（十分に近いか）」は分からない。
$\log p(y)$ 自体が未知だからである。

\paragraph{PSIS の $\hat k$}
「十分に近いか」を判定する指標として、\textcite{yao2018} はパレート平滑化重点サンプリング（PSIS）\parencite{vehtari2024} の $\hat k$ を提案している。
$q$ からのサンプル $z^{(s)}$ について重要度重み $w^{(s)} = p(y, z^{(s)}) / q(z^{(s)})$ を計算すると、$q$ が事後分布をよく近似していれば重みはほぼ均一になり、
$q$ が事後分布の重要な部分を取りこぼしていれば、ごく一部のサンプルが極端に大きな重みを持つ（重みの分布の裾が重くなる）。
重みの大きい側の裾に一般化パレート分布を当てはめ、その形状パラメータの推定値を $\hat k$ とする。
$\hat k < 0.5$ なら近似は良好で、重点サンプリングで補正すればさらに精度を上げられる、$0.5 \leq \hat k < 0.7$ ならまずまず、$\hat k \geq 0.7$ なら近似は信頼できない、というのが目安である。
本稿では、変分分布からの 1,000 サンプルで $\hat k$ を計算する。

$\hat k$ は、正解を知らなくても計算できる診断指標であり、運用時の監視指標の候補になる。
しかし本稿の SV モデルでは、提案手法を含むすべての変分族で $\hat k$ が 0.7 を超えた（提案手法でも 0.85。\cref{sec:synthetic}）。
次元が $T + k$ と高いと、1 次元あたりのわずかなずれが重みの対数の中で $T$ 個分積み上がるので、重みの分布の裾は重くなりやすく、$\hat k$ は悲観的な値になる。
変分族の良し悪しの順位とはおおむね整合したが、「0.7 を下回れば信頼してよい」という使い方はできない。
本稿では、$\hat k$ は補助的な指標とし、定期的に MCMC と結果を突き合わせることを主な検証手段とする（\cref{sec:system}）。
