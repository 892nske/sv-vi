実験コードは `experiments/`、生の結果は `results/`（git 管理外）、図は `docs/figures/`、表は `docs/tables/`。
環境：CPU 12 コア（WSL2）、GPU なし、JAX 0.12 / NumPyro 0.22、float64。乱数シードは 20261122。

## 結論（論文の主張に使えるもの）

1. **平均場 VI は SV モデルでは使えない。** φ が 0.03〜0.3 に崩れる（真値 0.97〜0.99）。
   「事後分散を過小評価する」という教科書的な問題以前に、**点推定そのものが大きく偏る**。
   h の事後 sd はむしろ NUTS の 1.3〜2 倍（φ が崩れて h がほぼ独立になり、ノイズを拾うため）。
   中心化・非中心化どちらでも同じ（S4）。NumPyro の AutoNormal・低ランク・フルランクも同様に崩れる（S2）。
2. **構造化 VI（θ と h を独立、h は三重対角精度）は h の推定は良いが、σ の不確実性を 1/5〜1/10 に過小評価する。**
   σ の 95% 区間の被覆率はほぼ 0（S1）。φ の区間も狭すぎる。σ 自体も過大（高持続で 0.20 vs 真値 0.10）。
3. **条件付き構造化 VI（提案）は NUTS とほぼ同等の精度。**
   - 復元精度（S1）：φ・σ の RMSE は NUTS と同程度。σ の被覆率 0.85〜1.0、h の被覆率 0.92〜0.97、h の事後 sd は NUTS の 0.93〜1.04 倍
   - NUTS との一致（S2, 高持続 T=1000）：φ 0.983 vs 0.983、σ 0.123 vs 0.126、事後 sd 比 φ 0.87・σ 0.90・h 0.98
   - φ の被覆率はやや低め（0.75〜0.95）、μ の事後 sd も過小（μ–φ のバナナ型の依存をガウスで表せない）
4. **速い。** T=10,000 で NUTS 548 秒（しかも θ の ESS は 14）に対し、提案 VI は約 11 秒で収束（約 50 倍）。
   有効サンプル数あたりで見ると差はさらに大きい。VI の時間は T に対してほぼ線形（O(T)）で、T≤2,000 では JIT コンパイル（約 2 秒）が大半。
5. **パラメータを増やすより構造を入れる方が効く。** NumPyro のフルランク（約 50 万パラメータ）は 230 秒かけても
   φ=0.24、σ=0.67 で、ELBO も最悪。提案手法のパラメータ数は約 2T。

## 各実験の要点

### S1 復元精度（表1 `tab1_recovery.tex`、表1b `tab1b_leverage.tex`、表1c `tab1c_student_t.tex`）
- 5 シナリオ × T∈{500, 2000} × 20 本。総計算時間 約 5.5 時間
- 低持続（φ=0.8）でも平均場は崩れる（φ の RMSE 0.72〜0.77）
- **t 誤差 SV**：提案手法は φ・σ とも良好（T=2000 で被覆 0.95/0.90）。ν は NUTS でも推定が難しい（T=500 で RMSE 約 12）
- **レバレッジ SV**：提案手法は φ・σ・h は良好だが、**ρ を 0 側に約 25% 縮める**（T=2000 で偏り +0.13、被覆 0.35、sd 比 0.65）。
  経緯：最初の版（q(h|θ) が ρ に依存しない）は ρ≈−0.08 とほぼ 0 に潰れた。遷移のイノベーション sd を σ√(1−ρ²) にし、
  リターン連動のドリフト ρσẽ_t（ẽ_t は変分パラメータ）を入れて ρ≈−0.37 まで改善。
  残りの偏りは、真のドリフト ρσ y_t e^{−h_t/2} が h_t に非線形に依存する部分をガウス族で表せないため（ステップ数・学習率を変えても不変）。
  → 論文では限界として明記し、今後の課題（非線形遷移を持つ変分族、正規化フロー等）とする

### S2 NUTS との一致度（図2 `fig2_h_bands`、図3 `fig3_theta_marginals`、図A1 `figA1_elbo`、表A2 `tabA2_agreement.tex`）
- 正解役の NUTS は 4 チェーン × (warmup 2000 + 32,000 ステップを 8 つおきに保存)、178 秒。R̂≤1.003、σ の ESS 約 800
- 自前の構造化と NumPyro の構造化（自作ガイド）は ELBO・推定値が一致（実装の検算になっている）
- ELBO の順位は品質の順位と一致：条件付き −1580 ＞ 構造化 −1586 ＞ 平均場 −1644 ＞ フルランク −1706

### S3 計算時間（図4 `fig4_scaling`、表A3 `tabA3_scaling.tex`）
- NUTS は warmup・sample 各 1000 × 4 チェーン並列。θ の最小 ESS は 6〜46 しかない（同じ時間でも得られる情報が少ない）
- VI の「収束までの時間」は収束判定（200 ステップ窓の ELBO 平均の相対変化 < 1e-4）に依存してばらつく。図は傾向として読む

### S4 感度分析（表A1 `tabA1_sensitivity.tex`、高持続 T=1000 × 5 本）
- 提案手法は中心化／非中心化で同じ結果（理論どおり）。σ の事前分布（HalfNormal / 逆ガンマ）、MC サンプル数（1/4/16）、
  学習率（0.003/0.01/0.03）を変えても φ・σ・sd 比はほぼ不変 → 設定に頑健
- 平均場は非中心化にしても崩れたまま。構造化は非中心化で σ の sd 比が 0.14→0.47 に改善するが不十分

## 注意点・限界（論文に書くこと）

- **S1 の NUTS は混合が十分とは言えない**：warmup・sample 各 2000 × 4 チェーンで、200 回中 156 回で θ の R̂ > 1.05
  （中央値の最小 ESS は 46）。h は R̂ 平均 1.02 で問題なし。NUTS 自身の 95% 区間の被覆率は 0.8〜1.0 なので結論は変わらないが、
  S1 は「真値との比較」を主とし、「NUTS との比較」は S2（長いチェーン）で行う、という書き分けをする。
  → 中心化 SV の NUTS で σ が混合しにくいのは既知の問題（Kastner & Frühwirth-Schnatter 2014 の ASIS の動機）。
  論文 7 章の「MCMC も万能ではない」という論点にも使える
- **PSIS k̂** は全手法で 0.7 超（提案手法でも 0.85）。T 次元の潜在変数では k̂ は悲観的に出る。本番監視の主指標にはしない
- 被覆率は 20 本の複製なので刻みが 0.05、誤差も ±0.1 程度ある
- 計時は WSL2 上の単一マシン。ほかの処理と重ならないよう S3 は単独で実行した
